# 🧪 Dashboard Testing Checklist

## Project
Semantic HTML5 Accessible Dashboard

## Testing
- Dashboard opens correctly.
- Total Users, Active Projects, and Completed Tasks are visible.
- Project data table displays correctly.
- Reports section displays monthly performance.
- Settings form has proper labels.
- Information dialog opens and closes.

## Accessibility
- Semantic HTML5 elements are used.
- Headings follow a logical order.
- Keyboard navigation works.
- Keyboard focus is visible.
- Tables have captions and proper headings.
- Form fields have labels.

## Responsive Design
- Dashboard works on mobile screens.
- Dashboard works on desktop screens.

## HTML Validation
- Check the HTML using the W3C Nu HTML Checker.
- Fix any reported HTML errors.
- Save a screenshot of the actual validation result.

Note: Mark tests as complete only after checking them.
