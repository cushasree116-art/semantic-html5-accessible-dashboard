# 📊 Semantic HTML5 Accessible Dashboard

## Project Overview
This project demonstrates an accessible dashboard using Semantic HTML5.

## Features
- Dashboard statistics
- Project data table
- Monthly performance reports
- Accessible settings form
- Information dialog

## Accessibility
- Semantic HTML elements
- Accessible navigation
- Proper form labels
- Keyboard navigation
- Visible focus indicators
- Accessible table headings

## Responsive Design
The dashboard is designed for mobile and desktop screens.

## HTML Validation
The HTML should be checked using the W3C Nu HTML Checker.

Validation results must be recorded after checking the actual HTML.

## Evidence
Project screenshots and validation evidence are stored in the docs folder.
