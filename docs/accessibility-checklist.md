# ♿ Accessibility Checklist

## Semantic HTML5
- Use header, nav, main, section, and footer.
- Use headings in the correct order.
- Provide accessible navigation.

## Forms
- Add labels to all form fields.
- Mark required fields clearly.
- Use fieldset and legend where appropriate.

## Tables
- Add a table caption.
- Use proper table headings.
- Use scope for table headers.

## Keyboard Accessibility
- Make controls usable with a keyboard.
- Show visible keyboard focus.
- Make the dialog easy to close.

## Responsive Design
- Check the dashboard on mobile.
- Check the dashboard on desktop.
- Ensure text is readable.

## Testing
- Check accessibility before marking items complete.
- Record actual results.
- Save screenshots of completed tests.
